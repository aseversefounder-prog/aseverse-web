# AseVerse MVP Investor Flow

## Locked Scope

No new feature expansion until this flow feels convincing.

## Reader Flow

Home -> Story Detail -> Dual Experience -> Community Reaction

This loop proves that readers can discover a story, understand its format, experience synced reading/listening, and react with the community.

## Creator Flow

Creator Dashboard -> Upload Story -> Publish Confirmation

This loop proves that creators can understand their performance, submit a story, and see a path toward monetization and narrator collaboration.

## Investor Demo Route

1. Open the app.
2. Browse featured stories.
3. Open a story.
4. Enter Dual Experience.
5. See comments/community reaction.
6. Switch to Creator Dashboard.
7. Upload a story.
8. Publish preview.
9. Return to creator metrics.

Target duration: under 3 minutes.

## Current Priority

The Dual Experience screen is the hero moment. Refinement should focus there before adding settings, notifications, account management, or deeper branches.
