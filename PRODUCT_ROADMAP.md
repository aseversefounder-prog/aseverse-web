# AseVerse Product Roadmap

## Current Rule

Keep the existing AseVerse UI/branding intact. The next work is functional MVP refinement, not aesthetic reinvention.

## Phase 1: Make The Demo Feel Real

Focus:

- Clickable navigation
- Smooth interaction polish
- Mock login/session state
- Mock story data
- Functioning reader page
- Functioning audio player UI
- Creator dashboard interactions
- Creator upload preview flow
- Profile state
- Mobile responsiveness
- Waitlist capture

Goal:

Create a demo strong enough for investors, early creators, hype clips, and beta waitlist collection.

## Phase 2: Real Backend

Add after the front-end stabilizes:

- Accounts
- Database
- Story uploads
- Cloud storage
- Comments
- Bookmarks
- Reading/listening progress
- Waitlist export/admin view

Goal:

Replace local mock state with real persisted user and creator data.

## Phase 3: Advanced Features

Save for later:

- Live collaboration
- AI narration systems
- Coin economy
- CarPlay
- Offline sync
- Creator monetization payouts
- Recommendation algorithm

Goal:

Expand only after the core reader and creator loops are proven.

## Founder Mode

Start building community before launch:

- Collect emails
- Document progress
- Post development clips
- Recruit beta readers
- Recruit small authors
- Recruit aspiring voice actors
- Capture feedback from every demo
